# 键盘测试页规格

> 引入版本：v1.0.7 开发中（2026-11-18）。入口：导航「测试」→ 顶部「鼠标 / 键盘」切换。
> 参考：zFrontier 在线键盘测试的**信息结构**（104 键布局、三态、日志、APM、清空、
> 日志/诊断标签、N 键无冲）；视觉、配色、尺寸按本项目 Win32/GDI+ 规范重做，
> 不照搬网页黑色卡片与字体。

## 1. 入口与状态

- 测试页顶部新增分段控件「鼠标 | 键盘」，默认鼠标；切换不丢失各自的统计。
- 键盘模式标题为「键盘测试」，副标题显示输入状态与「ANSI 104 键」。
- 键盘统计引擎 `KeyboardTestEngine` 属于 `MouseTestView`，纯逻辑、无窗口/GDI 依赖。
- 进入测试视图时同时注册 Raw Input：
  - 鼠标：UsagePage `0x01`、Usage `0x02`；
  - 键盘：UsagePage `0x01`、Usage `0x06`；
  - 均不使用 `RIDEV_INPUTSINK`，只统计本窗口获得焦点时的输入。
- 键盘事件：`WM_INPUT` → `GetRawInputData` → `RAWKEYBOARD`。
  - `RI_KEY_BREAK` 区分按下/释放；`RI_KEY_E0` 区分扩展键；`RI_KEY_E1` 不当作扩展位。
  - 自动重复（同一键已按下时的重复 KeyDown）只保持按下态，不重复记日志/APM。
  - 过载/占位报文（`VKey == 0xFF`、`MakeCode == KEYBOARD_OVERRUN_MAKE_CODE`）直接丢弃，
    不能进入引擎留下无法配对的按下态。
- 窗口失焦：记录一条 `Blur`，清空所有“按住”状态与同键间隔（不再伪造 KeyUp）；
  重新聚焦后从新事件继续。重新获得焦点时清除本次失焦的去重标记，
  因此每次失焦都能记录一条 `Blur`，不依赖中间是否按过键。
- 离开键盘页（切到鼠标、切到其它导航页、隐藏到托盘）：
  调用 `ReleaseAll()` 只清除“按住”状态，不伪造 KeyUp/Blur，也不写日志；
  回来后按下的键不会永久停在按下态，下一次真实按下仍会计数。

## 2. 数据模型

`src/keyboard_test.h`：

```text
KeyDef      code / 键帽主标签 / Shift 标签 / 日志名 / x,y,w,h(单位) / VK / MakeCode / 扩展位
KeyRuntime  down / tested / lastDownMs / prevDownMs / pressCount
Event       monoMs / keyIndex / Down|Up|Blur
KeyState    Untested | Down | Up
```

- 104 个键固定按 ANSI 全尺寸布局定义（主键区 + 导航区 + 数字小键盘）。
- 键码去重：
  - `VK_SHIFT` 按 MakeCode `0x2A`/`0x36` 映射左右 Shift；
  - `VK_CONTROL`/`VK_MENU` 按 `RI_KEY_E0` 映射左右；
  - `VK_RETURN` 按扩展位区分主 Enter / 小键盘 Enter；
  - `VK_CANCEL`（Ctrl+Pause/Break）映射到 `PAUSE`；
  - NumLock 关闭时导航键可能上报 `VK_HOME/UP/...` 且无 E0：
    按 MakeCode（`0x47..0x53`）映射到数字小键盘，不能点亮主方向键。
- 三态：未测试（无记录）、按下（当前 down）、已释放（tested && !down）。
- `Clear`：清空三态、日志、APM、连击计数、最大同时按下数。
  - 清空时若某些键仍被物理按住，引擎记录这些键并忽略其系统自动重复，
    直到收到对应 KeyUp；否则自动重复会在一个重复周期内把“已清空”重新点亮。
- KeyDown 时间戳另有独立存储（保留最近 30 s），日志环形缓冲（64 条）
  只服务日志显示；APM 与 30 s 直方图不得因日志淘汰而少算。

## 3. 指标

- **APM**：最近 5 秒内有效 KeyDown 次数 × 12；自动重复不计。
  顶部显示大号 `APM N`，并画最近 30 秒每秒按下次数折线。
  折线按每秒推进重绘，不能只在 APM 数值变化时刷新；
  高频率输入（5 秒内超过 32 次按下）也必须完整计入。
- **日志**：每条 `HH:mm:ss.mmm | 键名 | KeyDown/KeyUp/Blur`，最新在上，保留最近 64 条。
  KeyDown 用强调色，KeyUp 用次要色，Blur 用琥珀色。
- **诊断**：
  - N 键无冲：当前按住数 / 历史最大同时按住数；
  - 连击诊断：同一键相邻两次按下间隔 < 50 ms 计一次“疑似连击”；
  - 最近一次按键与同键间隔（ms）；
  - 已测试键数 / 104、当前按住数；
  - 提示：Win/Menu 可能被系统占用，浏览器/部分系统无法测试。
- **清空**：重置全部键盘统计，不改变当前鼠标目标/统计。
- **布局**：当前交付 ANSI 104 键；顶部显示「ANSI 104 键」徽标。
  多配列（60% / 75% / ISO / 日文）已由用户升为 **P0**，尚未实现；需要独立布局表、
  坐标、键码归一化、切换 UI、持久化与逐配列测试，见 §7。

## 4. 排版

```text
┌ 键盘测试 ────────────────────────────────────────────────────────────┐
│ [鼠标][键盘]   按下■ 已释放■ 未测试■        APM 12 ~30s 曲线  ANSI 104 键  [清空] │
├──────────────────────────────────────────────────────────────────────┤
│  104 键 ANSI 布局（整宽，主键区 + 导航区 + 数字小键盘）              │
│  ┌ESC┐ ┌F1..F12┐ ┌PRTSC/SCRLK/PAUSE┐ ...                            │
│  └───┘ └───────┘ └──────────────────┘                                │
├──────────────────────────────────────────────────────────────────────┤
│ [日志] [诊断]                                                        │
│ 08:35:11.384   A          KeyDown                                    │
│ 08:35:11.385   A          KeyUp                                      │
│ ...                                                                  │
└──────────────────────────────────────────────────────────────────────┘
```

- 内容区外边距 20；键盘板单位 = `min(可用宽 / 23.5, 可用高 / 6)`，
  宽高同时受限时保持 23.5:6 比例并在内容区居中；键帽圆角 5，键间距约 0.08 单位。
  不能只按宽度计算，否则超宽/矮窗口会把日志面板推出内容区。
- 键盘板下方日志/诊断面板的底边不得越过内容区底边；
  内容高度不足时先压缩键盘板，再压缩面板，诊断卡片高度按实际可用高度计算。
- 三态配色：
  - 未测试：白底、`kBorder` 边框、`kSub` 文字；
  - 按下：`kAccent` 实底、白字；
  - 已释放：`kAccentSoft` 底、`kAccent` 边框/文字。
- 键帽主标签居中；数字/符号键的 Shift 符号以 7pt 画在左上角；
  长标签（BACKSPACE/PRTSC）缩小并省略。
- 日志/诊断共用底部面板；标签切换只影响面板内容。
- 字体：键帽 9pt，Shift 符号 7pt，日志等宽 9pt；复用 `fontBody_/fontSmall_/fontBold_`。

## 5. 边界

- 键盘测试只读：不写入设备、不修改系统设置。
- PrtSc：Windows 11 的 Print Screen 会交给 Snipping Tool；应用侧
  `VK_SNAPSHOT + scan 0x37 + E0` 的映射/三态/日志/APM 由单测覆盖。
  真实注入两次均被系统在 Raw Input 前截走（日志只有 Blur、没有 PRTSC）；
  系统级实测需手动关闭“使用 Print Screen 打开屏幕截图”后按一次，不修改用户设置。
- 演示模式下鼠标测试仍暂停；键盘测试使用真实键盘输入，副标题注明。
- 页面按钮（模式切换、清空、日志/诊断标签）不产生键盘统计（键盘输入不按鼠标命中判定）。
- 不实现网页的按键声音、换键帽、显示音名、HID 描述符授权；这些是外观/浏览器能力，
  与输入统计无关。若后续需要另开规格。
- 不实现 N 键无冲的强制 10 键引导弹窗；用诊断区的实时“当前/最大同时按下”代替。

## 6. 验收

1. 进入「测试」→「键盘」，显示完整 104 键 ANSI 布局与三态图例。
2. 按 A：A 键变按下色、日志出现 KeyDown；松开后变已释放色、日志出现 KeyUp；APM 增加。
3. 自动重复：按住 A 不放，日志只有一条 KeyDown；松开一条 KeyUp。
4. 按左/右 Shift、Ctrl、Alt、主 Enter/小键盘 Enter：分别点亮对应键，不串键。
5. NumLock 关闭时按小键盘 7/8/9：点亮数字小键盘对应键，不点亮主 Home/Up/PgUp。
6. 同时按住 6 个以上键：诊断区当前按住数/最大同时数正确，显示 N 键无冲结果。
7. 同一键 30 ms 内连按两次：疑似连击 +1；间隔 >50 ms 不计数。
8. 「清空」后所有键回到未测试，日志/APM/连击/最大同时数归零；鼠标统计不受影响。
   按住某键时点「清空」，该键保持未测试，系统自动重复不得把它重新点亮；
   松开后再次按下，恢复正常计数。
9. 切回「鼠标」：鼠标测试原有目标、计数、轨迹保持。
   切换时若有键仍按住，键盘“按住”态被释放；切回键盘后不出现永久按下的键。
10. 窗口失焦：日志出现 Blur，按住态清空；重新聚焦后继续统计。
    连续两次失焦（中间不按键）应记录两条 Blur。
11. 最小窗口 1000×740、96 DPI 下键盘不重叠、日志面板不压住键盘；
    高 DPI 下键帽/字号按 `Scale()` 缩放。
12. 5 秒内按下 40 次：`APM 480`；30 秒直方图峰值与总次数一致，
    不因日志只保留 64 条而截断；停止按键后折线每秒左移。
13. 在键盘页悬停「清空」后把光标移到左侧导航栏：悬停高亮消失。
14. 超宽/矮窗口（如 3840×1080）下键盘板按高度收缩，日志/诊断面板仍在内容区内。

## 7. P0 后续：多配列（未实现）

> 2026-11-18 用户将「其它配列」优先度提升为 **P0**。当前仍是 ANSI 104，
> 以下为交付前必须补齐的规格要点；未完成前不得在看板/README 中声称支持。

### 7.1 配列范围

- **60%**：无独立功能行/导航区/数字小键盘，约 61 键；保留 Esc、Backspace、Enter、
  Shift/Ctrl/Alt/Win/Menu、方向键与 Fn 组合（Fn 本身通常不上报 Raw Input）。
- **75%**：紧凑功能行 + 导航列 + 方向键，约 84 键；无数字小键盘。
- **ISO**：在 ANSI 基础上增加 `IntlBackslash`（`VK_OEM_102` / scan `0x56`），
  Enter 为 L 形（布局上可用两行高/宽矩形近似）；键帽标签按 ISO 绘制。
- **日文 JIS**：在 ANSI/ISO 基础上增加 `Lang1`（英数）、`Lang2`（かな）、
  `Convert`、`NonConvert` 等，约 109 键；空格键更短，Enter/Shift 行不同。
- 不包含 40%、Alice、分体、客制化矩阵；这些需要单独布局表，另开规格。

### 7.2 数据模型

- 每个配列一张 `KeyDef` 表（code / label / shiftLabel / name / x,y,w,h / VK / MakeCode）。
- 引擎不再固定 `kKeyCount = 104`：允许按配列传入键数，`KeyRuntime` 按最大键数
  （≥128）预分配，对外暴露当前配列的 `KeyCount()`。
- `ResolveKey` 必须按当前配列查表；ISO/JIS 额外键按 VK + scan + E0 归一化。
- 切换配列时清空键盘统计与日志（键下标不可跨配列复用），并记录一条
  `LayoutChange` 事件或诊断提示；不伪造按键事件。

### 7.3 UI 与持久化

- 键盘工具行把静态「ANSI 104 键」徽标改为配列下拉/分段：ANSI 104 / 60% / 75% / ISO / 日文。
- 默认 ANSI 104；选择写入本应用配置，下次进入保持。
- 键盘板宽度按配列画布单位计算，仍受 `min(宽/画布宽, 高/6)` 与面板最小高度约束；
  板在内容区水平居中。
- 键帽标签沿用现有 9pt/7pt 规则；ISO/JIS 长标签按需省略。

### 7.4 验收（实现后）

1. 切换到每种配列：键数、行列、功能键/导航/方向键位置正确，无重叠、无越界。
2. 按键点亮与日志使用该配列的键名；ISO `IntlBackslash`、JIS `Lang1/Lang2/Convert`
   能正确归一化。
3. 切换配列后统计清零；切回 ANSI 仍正常，配置持久化。
4. 1000×740、125%/150% 合成 DPI、超宽/矮窗口下键盘板与日志/诊断面板完整。
5. 每种配列至少一组布局/键码单测；16 套件保持通过。
