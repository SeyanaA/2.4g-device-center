# 电量通知规格

> 状态：实现中 · 适用 v1.0.5+
>
> 目标：低电量、严重低电量和充电完成都通过 Windows 系统通知展示，而不是只改托盘图标。

## 1. 数据源

使用 `DeviceManager` 已经合并后的设备快照，每个物理设备一条状态：

- `identity` 非空时作为去重 key，否则用 `id`。
- 只在 `online == true && batteryValid == true && battery >= 0` 时评估；休眠/离线/无读数不触发，也不改状态。
- `battery` 是设备原始百分比；`charging` 是设备上报的充电位。
- demo 模式不发送真实通知。

## 2. 触发规则

| 事件 | 条件 | 标题 | 级别 |
| --- | --- | --- | --- |
| 低电量 | 未充电，`battery <= 20%`，本放电周期未通知过 | 电量偏低 | 警告 |
| 严重低电 | 未充电，`battery <= 10%`，本放电周期未通知过严重级 | 电量严重不足 | 警告 |
| 充电完成 | 充电中且 `battery >= 100%`，或充电位从 1 变为 0 且 `battery >= 99%` | 充电完成 | 信息 |

严重低电和低电可以先后各发一次：先到 20% 发“电量偏低”，继续降到 10% 再发“电量严重不足”。

## 3. 去重与重置

- 每个设备独立保存：上次充电位、是否已发低电/严重低电/充满。
- 低电/严重低电：
  - 充电开始（0→1）时清除低电标记；
  - 电量回到 `> 25%` 时清除低电标记；
  - 标记清除后再次跌破阈值才会重新通知。
- 充电完成：
  - 充电开始且电量 `< 99%` 时重新武装；
  - 未充电且电量 `< 90%` 时重新武装；
  - 同一充电周期只通知一次，100% 插着电不会每分钟重复。
- 首次看到设备：
  - 如果未充电且已经低电，立即发低电/严重低电；
  - 如果正在充电/已满，不发“充电完成”，避免启动即弹窗。

## 4. 状态机

```text
未见过 --(首次, 未充电, <=20)--> 低电已通知
未见过 --(首次, 未充电, <=10)--> 严重低电已通知
未见过 --(首次, 充电)-----------> 充电中（不弹“完成”）

充电中 --(battery>=100, 仍充电)--> 已通知完成
充电中 --(1->0, battery>=99)-----> 已通知完成
充电中 --(1->0, battery<99)------> 未完成（不通知）

低电已通知 --(battery<=10)-------> 严重低电已通知
低电/严重低电 --(开始充电)--------> 清除低电标记
低电/严重低电 --(battery>25)------> 清除低电标记
已通知完成 --(battery<90 且未充电)--> 重新武装
```

## 5. 平台实现

- 复用 `TrayIcon::Balloon()`：`Shell_NotifyIconW(NIM_MODIFY, NIF_INFO)`。
- Windows 10/11 会把它显示为系统通知并保留在通知中心；不需要 WinRT/AUMID/快捷方式。
- 低电/严重低电用 `NIIF_WARNING`，充电完成用 `NIIF_INFO`。
- 通知正文包含设备名和当前百分比，例如：
  - `Zaopin Z4D 剩余 15%，请及时充电。`
  - `Zaopin Z4D 仅剩 8%，请立即充电。`
  - `Zaopin Z4D 已充满（100%）。`
- 发送前读取 `HKCU\Software\Microsoft\Windows\CurrentVersion\PushNotifications\ToastEnabled`：
  - 为 `0` 时不调用 `Balloon`、不推进状态机；底部显示“系统通知已关闭”，首次发现时在应用内提示一次。
  - 托盘菜单增加“通知设置”，用 `ShellExecute` 打开 `ms-settings:notifications`。
  - 托盘菜单增加“发送测试通知”，用同一条 `Balloon` 路径发一条信息通知，方便确认系统设置。
  - 用户重新打开系统通知后，下一次快照会重新评估当前电量并补发尚未确认的低电/充满事件。
- `Shell_NotifyIcon` 返回成功不代表通知一定展示；以 Windows 总开关为准，不在应用内循环重试。

## 6. 验收场景

1. 未充电 15% → 一次“电量偏低”；下一轮 15% 不重复。
2. 继续降到 8% → 一次“电量严重不足”。
3. 插电后低电标记清除；拔电仍在 8% → 再次“电量严重不足”。
4. 充电 80% 拔掉 → 不报“充电完成”。
5. 充电 100%（仍显示充电）→ 一次“充电完成”；继续保持 100% 不重复。
6. 充电 99% 拔掉 → 一次“充电完成”。
7. 启动时已 100% 且正在充电 → 不弹“充电完成”。
8. 两台设备分别低电 → 各自通知，互不影响。
9. demo 模式、离线设备、无电量读数 → 不发通知。
