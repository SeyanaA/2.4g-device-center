# 日志视图与导出规格

> 状态：实现中 · 目标版本 v1.0.8
>
> 目标：设备页直接显示 7 天电量曲线；日志视图显示鼠标活动日志，
> 时间尺度按 1–7 天选择，超宽时用底部横向滚动条查看；支持导出 CSV/TXT。
> 关闭窗口时由用户决定「退出」还是「后台运行」。

## 1. 关闭窗口

`WM_CLOSE` 不再直接隐藏到托盘，而是弹出确认框（`MB_YESNOCANCEL`）：

| 选择 | 行为 |
| --- | --- |
| 是 | 退出程序（停止扫描、移除托盘图标、销毁窗口） |
| 否 | 最小化到托盘，继续后台扫描（当前默认行为） |
| 取消 | 不关闭，保持原状 |

- 默认按钮为「否」，避免误按回车退出。
- 托盘菜单「退出」仍然直接退出，不弹确认框。

## 2. 设备页

- 右侧内容（设备卡、电量、DPI、性能、电量曲线）放在一个纵向滚动区域内：
  - 内容高度超过可视区时，右侧出现**细胶囊竖向滚动条**（6 px、无轨道/箭头，可拖动）；
  - 鼠标滚轮在右侧内容区滚动；
  - 内容不足一屏时滚动条不显示。
- 「应用设置」按钮移到标题栏，位于「日志」左侧。
- 底部迷你电量曲线（固定比例，约 280 px 高，随卡片宽度铺满）：
  - 内容：所选设备最近 7 天电量折线 + 折线下方浅蓝面积填充；
  - 标题「电量曲线 · 最近 7 天」，右侧显示「当前 NN%」；
  - Y 轴按 7 天数据自适应（最少 20 个百分点），标注 3 条刻度；
  - 没有数据时显示「最近 7 天暂无电量记录」；
  - 点击卡片进入日志视图（并匹配当前设备）。

## 3. 日志视图（内嵌主界面）

- 主界面标题栏按钮在「日志」/「返回」之间切换；不打开独立窗口。
- 托盘菜单「日志与电量曲线」显示主窗口并切到日志视图。
- 日志视图占满内容区（设备列表与右侧卡片隐藏）：

```text
[设备 ▼] [范围 1..7 天 ▼]                 [导出] [打开文件夹]
┌──────────────────────────────────────────────────────────┐
│ 电量曲线 · 最近 N 天                      当前 56% · 7 天 +0% │
│  65 ┤                                                    │
│  55 ┤      ●────●────●                                   │
│  45 ┴──┬─────┬─────┬─────┬─────┬─────┬─────┬──           │
│      11/08 11/09 11/10 11/11 11/12 11/13 11/14           │
│      ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓（横向滚动条）│
└──────────────────────────────────────────────────────────┘
鼠标活动日志 · 最近 N 天（X 条）
┌──────────────────────────────────────────────────────────┐
│ 时间          类型   设备          详情                   │
└──────────────────────────────────────────────────────────┘
```

- 设备下拉：`全部设备` + 日志里出现过的 identity（按最近出现排序）。
- 进入日志视图时优先选中主界面当前设备，实现「在主界面上匹配查看」；
  之后 10s 自动重读与「刷新」保留当前选择（含「全部设备」），不重置回当前设备。
- 范围下拉：1–7 天，按本地自然日计算；影响曲线、列表与导出。
- 鼠标活动日志只显示 `CONNECT` / `DISCONNECT` / `BATTERY` / `CHARGE`；
  `SAMPLE` 是我方 30 分钟采样，只用于画曲线，不进入列表与导出。
- 曲线宽度：每天固定 220 px（96 DPI）；1 天铺满画幅，2–7 天按比例加宽。
  内容超过画幅时，卡片底部出现**细胶囊横向滚动条**（6 px、无轨道/箭头，可拖动），
  也可用鼠标滚轮左右查看；首次进入及切换时间范围后停在最右（最近数据）；
  内容不足一屏时滚动条不显示。
- 刷新：重新读取 7 天日志；日志视图每 10s 也会自动重读一次。
- 只读：视图不提供删除、编辑、写入设备的能力。
- 退出应用时无需额外关闭窗口（视图属于主窗口）。

## 4. 曲线数据

数据源：`events-YYYY-MM-DD.log`（保留 7 天，见 `SPEC-logging.md`）。

- 时间窗口：`今天 - (N-1) 天 00:00` 到 `明天 00:00`，N 取 1–7。
- 取值事件：`CONNECT`、`BATTERY`、`SAMPLE`、`DISCONNECT` 中带 `pct=NN` 的记录；
  `CHARGE` 只用于切换后续点的颜色，不单独成点。
- 单设备：普通放电段蓝色 `#2563EB`，充电段绿色 `#16A34A`。
- 全部设备：按设备配色（蓝/绿/橙/紫），不区分充电段，右上角显示图例。
- Y 轴自适应：按所选 N 天内可见样本自动取范围并留 2 点余量，最少 20 个百分点，
  这样 1–5% 的变化也看得出来；没有数据时退回 0–100。
- X 轴每天一条竖线并标 `MM/DD`；单日尺度下额外画 6 小时辅助线。
- 单设备摘要：`当前 95% · 7 天 -5%`；数据足够时追加
  `预计续航 ≈ 32 小时`（未充电样本 ≥ 2 小时、放电速率 > 0.05%/h 才显示）。
- 7 天以外数据不读取、不显示（与日志保留策略一致）。

## 5. 采样事件

为了让「电量不变」时曲线仍有走势，`DeviceManager` 每 30 分钟补一条 `SAMPLE`：

- 只对 `online && batteryValid && battery >= 0` 的设备；
- 同一 identity 距上次采样 `>= 1800s` 才写，应用重启后重新计时；
- 不改变 `BATTERY`（跳变）与 `CHARGE`（充电位翻转）的原有语义；
- 明细带 `pct=NN`、`chg=0/1`、`mv=NNNN`，旧格式回退到 `NN%` 文本；
- SAMPLE 只供曲线使用，不出现在活动日志列表与导出文件中。

## 6. 导出 CSV / TXT

- 「导出」按当前范围（设备 + N 天）导出活动日志，不含 `SAMPLE`。
- 保存对话框默认文件名：`2.4GCenter-events-YYYYMMDD.csv`。
- CSV：UTF-8 带 BOM，表头 `时间,类型,设备,identity,详情`；逗号/引号按 RFC4180 转义。
- TXT：与 `events-*.log` 相同的行格式。
- 扩展名决定格式：用户输入 `.txt` 写文本，其余写 CSV。
- 导出成功/失败用底部 toast 提示；取消对话框不提示、不写文件。
- 导出只读取内存中的事件记录，不修改日志文件。
- 导出使用点击「导出」时的记录快照；保存对话框打开期间发生的 10s 自动重读
  不影响本次导出内容，也不会造成崩溃。

## 7. 解析与容错

- 一行格式：`YYYY-MM-DD HH:MM:SS  TYPE  identity  name  detail`。
- 时间、类型、identity 必须完整；缺字段的行跳过，不影响其他行。
- 文件不存在、编码损坏、目录被删除：显示空状态，不弹错误框。
- 最多读取 7 个文件；单文件超过 4 MB 也照常按行读取。

## 8. 验收场景

1. 点窗口 X → 弹框；选「取消」窗口保持；选「否」隐藏到托盘且扫描继续；选「是」进程退出。
2. 托盘「退出」不弹框，直接退出。
3. 设备页底部出现 7 天迷你曲线；点击进入日志视图。
4. 主界面「日志」按钮切到日志视图，按钮变「返回」；再点回设备视图。
5. 进入日志视图时下拉自动选中主界面当前设备。
6. 范围 7 天：曲线每天 220 px，超出画幅，底部出现横向滚动条；
   拖动/滚轮可查看最早几天；首次进入即停在最右（不因 10s 重读跳到最旧）。
7. 范围 1 天：曲线铺满画幅，滚动条隐藏。
8. 活动日志只显示接入/断开/电量/充电，不含「采样」行。
9. 没有任何数据：显示空状态，不崩溃。
10. 删除 `events` 目录后打开：空状态；刷新不崩溃。
11. 导出 CSV：BOM + 表头 + 当前范围的行；逗号/引号正确转义；toast 显示条数。
12. 导出 TXT：行格式与日志文件一致；取消保存对话框不生成文件。
13. 采样：连续运行 35 分钟，日志出现至少 1 条 `SAMPLE`；30 分钟内不重复。
14. 选择「全部设备」后等待 10s 自动重读：下拉仍为「全部设备」，列表不跳回单设备。
15. 打开保存对话框停留 >10s 再保存：CSV/TXT 正常生成，进程不崩溃。
