# 鼠标测试页规格

> 版本：资源 1.0.7.0（2026-11-18 加入「鼠标 / 键盘」切换；鼠标部分沿用 2026-11-14
> 的按键命名顺序、页面点击泄漏、重新检测清零、路径长度、等比缩放与滚轮高亮修正）
> 参考：mousetester.cn 的信息结构（按键/双击/滚轮、回报率、点击速度、轨迹），
> 视觉与排版按本项目 Win32/GDI+ 设计规范重做，不照搬网页配色与尺寸。

## 1. 入口与状态

- 左侧导航栏「测试」进入输入测试视图，顶部可切换「鼠标 / 键盘」
  （键盘规格见 `SPEC-keyboard-test.md`）；日志仍由导航栏「日志」进入。
  - 托盘菜单提供「鼠标 / 键盘测试」。
- `MainWindow` 持有 `MouseTestView testView_`，统计引擎 `MouseTestEngine` 属于视图；
  进入测试视图时注册 Raw Input，离开时注销并停止重绘定时器。
- Raw Input：
  - `RegisterRawInputDevices`，UsagePage `0x01`、Usage `0x02`；
  - 不使用 `RIDEV_INPUTSINK`：只统计本窗口获得焦点时的输入；
  - 窗口 `WM_INPUT` → `MouseTestView::HandleRawInput` → `GetRawInputData` →
    取 `RAWMOUSE` → 按字段过滤后交给 `MouseTestEngine::AddMouse`。
- 设备过滤：
  - 顶部下拉列出快照中 `Kind::Mouse` 的设备 + `任意鼠标`；
    首次进入且用户尚未手动选择时，默认选中快照里当前选中的设备（若是鼠标）。
  - 用户在下拉框里显式选择过之后，后续设备刷新不再覆盖该选择。
  - 进入时用 `GetRawInputDeviceList` + `RIDI_DEVICENAME` 匹配目标设备的
    `path/basePath`（先整段包含，再 vid/pid），得到 `hDevice`。
  - 匹配失败时暂停统计并在顶部提示，不得静默回落成“任意鼠标”。
  - 「重新检测」重新匹配句柄并清零全部统计（计数、双击、滚轮、CPS/最佳、
    轨迹、路径长度、回报率采样；与「重置」走同一条重置路径）。
- 统计区域（按字段判定，不按整条报文判定）：
  - 按键/滚轮：只有光标位于左侧「按键与滚轮」卡的鼠标图形区域内时，
    报文里的 `usButtonFlags/usButtonData` 才计入统计；同一报文中的移动分量
    另有独立门槛（见下一条）。
  - 移动/回报率/轨迹：光标位于测试视图内容区、48px 内容头与工具行之外，且不在任何
    页面按钮上时计数。
  - 一条报文可能同时携带移动和按键：先把不允许的字段清零再交给引擎，
    禁止因“报文里包含移动”而让按键/滚轮整体通过。
  - 页面按钮永远不计入统计：工具行的「鼠标 / 键盘」切换、目标下拉、「重新检测」
    「5s/10s」「重置」，以及轨迹卡内部的「清空轨迹」。
- 刷新：50 ms 定时器，只在有数据变化时 `InvalidateRect`；不在 `WM_INPUT` 里直接重绘。

## 2. 指标定义

### 2.1 按键与滚轮卡

- 按键命名与计数下标统一按 `RAWMOUSE` 的 `RI_MOUSE_BUTTON_1..5` 顺序：
  0=左键、1=右键、2=中键、3=后退、4=前进。注意 `BUTTON_2` 是右键、`BUTTON_3` 是中键，
  与“左/中/右”的日常顺序不同；显示名统一由 `MouseButtonName()` 提供。
- 鼠标图形内部的高亮使用另一套图形顺序 `pressed_`：0=左、1=中、2=右、3=后退、4=前进；
  两套编号不得混用，也不得据此调整计数下标。
- 双击检测：同一按键两次按下间隔 ≤ 500 ms 记为一次双击；
  间隔 < 80 ms 记为「疑似故障双击」；记录最小间隔与故障次数。
  双击/故障是五个按键的汇总值，不区分按键；界面文案不得声称是某一个按键（如「左键」）。
- 滚轮：`RI_MOUSE_WHEEL` 的 `usButtonData` 累加，±120 为一格；
  分别统计上滚/下滚格数；滚动速度按最近 1 s 格数计算「格/秒」。
  滚轮没有“按下”事件，每个滚轮事件让图形中的滚轮位短暂高亮一次（复用按键的 160 ms 高亮）。
- 双击/疑似故障提示横跨整张卡片，不放在某一按键列下。
- 底部按键统计卡：五列分别显示每个按键的总次数（顺序同上）；
  下方整行显示汇总状态——有故障时为琥珀色「疑似故障双击 N 次（最短 X ms）」，
  否则为绿色「各键计数正常」。

### 2.2 回报率卡

- 采样：相邻两次鼠标移动 Raw Input 的 `QueryPerformanceCounter` 间隔；
  忽略 < 50 µs、> 50 ms 的间隔；环形缓冲保留最近 4096 个。
- 中位间隔 → 中位回报率 `Hz = 1e6 / median_us`。
- 稳定性：
  - 落在中位间隔 ±10% 内的样本占比 ≥ 90% → 「稳定」；
  - ≥ 70% → 「一般」；否则「不稳定」。
- 分桶（相对中位间隔）：`≤-20%`、`-10%`、`±10%`、`+10%`、`≥+20%`，显示百分比。
- 展示：大号 Hz、中位间隔 µs、样本数、±10% 占比、五段分布条。
- 「重新检测」清空全部统计（含回报率采样）并重新匹配目标句柄。

### 2.3 点击速度卡

- 只统计左键按下；滚动窗口 5 s / 10 s（顶部切换）。
- 当前 CPS = 窗口内点击次数 / 窗口秒数。
- 历史最佳 CPS 按同一窗口长度分别记录 5 s 与 10 s 两个值，`Reset` 清空。
- 展示：大号 CPS、窗口选择、最佳记录、环形进度（相对本轮最大值，避免假刻度）。

### 2.4 轨迹卡

- 以进入测试或上次清零为原点，累加 `lLastX/lLastY` 相对位移。
- 采样点上限 32768；绘制时按点数上取整下采样，最多约 2000 段（含收尾段不超过约 2001 段），
  避免 `size/2000` 向下取整时在 2000–3999 点之间画出近 4000 段。
- 路径长度：每段累计曼哈顿距离 `|dx| + |dy|`，作为 `MouseTestSnapshot.pathLength`
  显示在轨迹卡底部；随「清空轨迹」「重置」「重新检测」清零。
- 跳点：单次 `|dx| + |dy| > 200` 计一次跳点，用琥珀色圆点标出。
- 最长中断：相邻移动报文的 QPC 间隔最大值（ms）。
- 展示：`报告 N`、`路径 N`、`跳点 N`、`最长中断 X ms`、`[清空轨迹]`。
- 轨迹随画布缩放：X/Y 共用同一比例 `min(w/spanX, h/spanY)`，并在画布内居中，
  不分别拉伸；空白时显示「移动鼠标以绘制轨迹」。

## 3. 排版（1280×800 内容区为基准，最小窗口 1000×740）

```text
┌ 测试 ──────────────────────────────────────────────────────────────┐
│ 目标设备 [下拉]   [重新检测]      窗口 [5s][10s]   [重置]   状态提示 │
├───────────────────────────────┬────────────────────────────────────┤
│ 按键与滚轮（约 330 px 高）    │ 回报率（约 150 px）                │
│  ┌ 鼠标图形 ─┐  左 17         │  2377 Hz · 中位 420 µs · 稳定      │
│  │ 左/右/中  │  右 3          │  分桶条 + ±10% 占比                │
│  │ 侧键/滚轮 │  中 10         ├────────────────────────────────────┤
│  └──────────┘  后退 0 前进 0  │ 点击速度（约 150 px）              │
│  双击 N · 滚轮 上 75 下 157   │  31 次/秒 · 最佳 6.2 · 5s/10s      │
│  疑似故障双击 M（整卡横跨）   │                                    │
├───────────────────────────────┼────────────────────────────────────┤
│ 按键统计（约 120 px）         │ 轨迹（约 230 px）                  │
│ 左 17 · 右 3 · 中 10          │ 路径画布 + 跳点（等比居中）        │
│ 后退 0 · 前进 0               │ 报告 N · 路径 N · 跳点 N           │
│ 疑似故障双击 M（整行跨度）    │ 中断 X ms · [清空轨迹]             │
└───────────────────────────────┴────────────────────────────────────┘
```

- 左列宽度约 55%，右列约 45%；卡片间距 12 px，内容区外边距 20 px。
- 内容高度不足时卡片底边按最小高度夹紧（说明卡 ≥80 px、轨迹卡 ≥120 px），不出现半张卡片。
- 卡片、字体、颜色复用 `FillRounded`、`DrawCard`、`DrawBadge`、`DrawTextIn`、
  `fontTitle_/fontBody_/fontSmall_`、`kCard/kBg/kAccent/kGreen/kAmber/kMuted`。
- 不使用网页的黑色卡片/橙色强调；保持本应用浅色卡片风格，强调色仍为蓝色。

## 4. 交互与边界

- 进入测试视图不改变当前选中设备；离开后恢复设备页布局。
- 测试视图不写设备、不修改任何设置；只读输入统计。
- 窗口失焦时 Raw Input 不再到达，统计暂停但不丢失已有结果。
- 设备拔插：目标句柄失效时顶部提示「目标设备已断开」，统计停止，且不得静默
  回落成「统计任意鼠标」；目标设备名/id 保留，重新插上后自动恢复匹配与统计，
  「重新检测」也可手动重试。
- 悬停高亮：鼠标移到页面按钮上时高亮；离开窗口（`WM_MOUSELEAVE`）或移到
  导航栏等非内容区后清除，不得残留。
- 高回报率（8 kHz）：每帧只做 O(1) 累积，绘制按 50 ms 节流；
  轨迹点环形覆盖，避免内存增长。
- `--demo` 下不注册鼠标 Raw Input（没有真实鼠标目标），顶栏状态显示
  「演示模式 · 不统计真实输入」；键盘 Raw Input 仍注册，键盘页使用真实输入。

## 5. 验收场景

1. 点击左侧导航「测试」进入页面；「设备 / 日志」导航可切走；顶部「鼠标 / 键盘」切换。
2. 在鼠标图形区域内点击左/右/中/后退/前进：五列数字与物理按键一一对应
   （右键不得落到中键列、中键不得落到右键列）；点「重置」后清零。
3. 连续快速双击：双击次数增加；间隔 < 80 ms 时显示「疑似故障双击」与最小间隔；
   提示文案与位置不绑定「左键」，而是整卡/整行跨度显示。
4. 滚轮上/下滚动：格数增加，最快格/秒更新；滚动时图形中的滚轮位短暂高亮。
5. 快速移动鼠标：回报率显示中位 Hz、样本数、稳定性与五段分布；
   1 kHz / 2 kHz / 4 kHz 设备读数与厂商标称一致（±10%）。
6. 点击速度：5 s/10 s 窗口切换，当前 CPS 与最佳记录合理。
7. 轨迹：移动时绘制路径；快速甩动出现跳点；停止移动后「最长中断」更新；
   「清空轨迹」清空画布与统计（含路径长度）。
8. 点击页面按钮（「鼠标 / 键盘」切换、「重新检测」「5s/10s」「重置」与轨迹卡
   「清空轨迹」）不会被计入鼠标点击/双击；划过工具行也不会产生移动样本；
   含移动分量的混合报文也不能让按键/滚轮漏进来。
9. 拔掉目标鼠标：提示断开；重新插上后「重新检测」恢复统计。
10. 「重新检测」后所有统计归零（计数、双击、滚轮、CPS/最佳、轨迹、路径长度、回报率），
    并重新匹配目标句柄。
11. 首次进入测试页时，下拉框默认选中设备页当前选中的鼠标（而不是「任意鼠标」）；
    手动改选「任意鼠标」后，设备刷新不再把选择切换回默认设备。
12. 鼠标移出窗口或移到导航栏后，页面按钮的悬停高亮消失。
13. 8 kHz 鼠标连续移动 30 s：UI 不卡顿、内存稳定、回报率读数不崩。
